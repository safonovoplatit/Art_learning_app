# Галерея

Нативное приложение для iPhone с iOS 18 и выше. Карточки открытой коллекции Чикагского института искусств можно перелистывать, увеличивать и сохранять в избранное.

## Запуск

1. Откройте `ArtGallery.xcodeproj` в Xcode. Самостоятельный проект находится в каталоге исходников.
2. Выберите схему **ArtGallery**, симулятор iPhone и нажмите Run. Первое наполнение коллекции требует подключения к интернету.
3. Для установки на физический iPhone выберите свою команду в **Signing & Capabilities**, задайте доступный вам Bundle Identifier и запустите проект на устройстве.
4. Для TestFlight создайте запись приложения в App Store Connect, выберите ту же команду и идентификатор, затем выполните **Product → Archive → Distribute App**. Для этого нужен доступ к программе Apple Developer.

Конфигурация Release включена в общую схему. Команда сборки для проверки компиляции без подписи:

```sh
xcodebuild -project ArtGallery.xcodeproj -scheme ArtGallery \
  -configuration Release -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```

## Архитектура

- **Domain** содержит `Artwork`, версионированную модель перевода и протоколы источника и репозитория.
- **Data** содержит адаптер `ChicagoAPI`, отдельные DTO, преобразование HTML в обычный текст через системную libxml2, репозиторий SwiftData, `ImagePipeline` и `TranslationService`. Для нового музея нужен адаптер `MuseumAPIProvider` и идентификатор источника в `MuseumSource`.
- **Features** содержит модель экрана галереи, пагинатор, карточку, избранное и полноэкранный просмотр. `MyApp` собирает зависимости и передаёт их модели.
- Внешних пакетов нет. Музейный поиск и пагинация используют [Art Institute of Chicago API](https://api.artic.edu/docs/). Изображения запрашиваются через IIIF по адресу из ответа API. Перевод работает через [Apple Translation](https://developer.apple.com/documentation/translation/).

## Хранение данных

SwiftData хранит оригиналы карточек, переводы, порядок выдачи, последнюю позицию, отметки просмотра и избранное. Страница и курсор фиксируются одной транзакцией. Данные о просмотре остаются на устройстве.

Декодированные изображения хранятся в `NSCache` с бюджетом 48 МБ. При системном предупреждении о памяти кэш очищается. Дисковый кэш ограничен 300 МБ, изображения избранного хранятся отдельно с лимитом 100 МБ. При достижении лимита первыми удаляются дольше всего не использовавшиеся файлы. Ответы с `Cache-Control: no-store` пишутся только в память на время отображения. Метаданные остаются доступны при вытеснении изображения. На устройство загружаются варианты IIIF шириной 600 или 843 px. Для увеличиваемого полноэкранного изображения используется вариант до 1800 px. Загрузка и декодирование выполняются вне главного актора, одновременные запросы одинакового URL объединяются.

Галерея принимает изображения только с подтверждённым флагом `is_public_domain`. Карточка показывает страницу источника, кредитную строку и условия атрибуции. Обозначение зала цитирует каталог. Поле `description` атрибутируется музею и лицензии CC BY 4.0. [Условия использования изображений](https://www.artic.edu/image-licensing).

## TranslationService

`GalleryTranslation` создаёт привязанную к представлению системную сессию и проверяет доступность пары английский → русский. Установленный пакет используется автоматически. При необходимости можно загрузить его с помощью кнопки в панели навигации и системного диалога. До завершения перевода и при неподдерживаемой паре отображается оригинал.

Работы переводятся последовательно с приоритетом текущей, следующей и предыдущей карточек. Кэш хранит оригинальные поля, идентификатор работы, пару языков и версию перевода. При изменении исходного текста или версии результат считается устаревшим. UI сохраняет авторские написания из словаря для распространённых имён художников.

## ArtworkPager

Компонент держит текущую карточку и до двух соседних. Горизонтальное смещение следует за пальцем. На краях применяется сопротивление. Переход срабатывает после 22% ширины или по прогнозу для короткого быстрого движения. При завершении пружинной анимации сохраняется новый индекс и срабатывает тактильная обратная связь. Стрелки и действия VoiceOver дублируют навигацию. Reduce Motion выключает параллакс.

## Тесты

В Xcode запустите **Product → Test** на симуляторе iPhone. Unit-тесты проверяют декодирование, HTML, фильтрацию, пороги жестов, дедупликацию, восстановление позиции и кэш перевода. UI-тесты работают на локальных данных с подменой музейного API и изображений.

## Ограничения и приёмка

- Системные пакеты Apple Translation и качество перевода проверяются на физическом iPhone.
- Для приёмочного замера FPS, холодного старта, памяти и утечек нужен физический iPhone и прогон Instruments, включая сценарий со 100 переходами.
- Включён один музейный источник. Проверка прав выполняется при получении ответа API. Исторический кэш без нового ответа сохраняет последний известный статус.
- Доступность музейных JPEG зависит от IIIF и сети пользователя. В среде разработки музейный API вернул страницы каталога, а отдельный домен IIIF вернул HTTP 403 с проверкой Cloudflare. Для карточки предусмотрено состояние ошибки с повторной попыткой.

## Установка готовой сборки на симулятор

Распакуйте `Artifacts/ArtGallery-Simulator-arm64.zip` на Mac с Apple Silicon. Запустите симулятор iPhone. Из каталога с распакованным приложением выполните:

```sh
xcrun simctl install booted ArtGallery.app
xcrun simctl launch booted org.artgallery.ios
```

`Artifacts/ArtGallery-iPhone-unsigned.zip` содержит Release для физического устройства без подписи. Инструкция по установке с вашей подписью приведена выше.
